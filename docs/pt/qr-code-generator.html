Perguntas frequentes

Como fazer um QR Code para um link?

Digite ou cole o link na caixa. O QR Code aparece na hora. Clique em Baixar para salvar como imagem.

O QR Code expira?

Não. O código contém o seu link ou texto, então funciona para sempre e não depende deste site.

Posso fazer um QR Code do WiFi?

Sim. Escolha Rede WiFi, digite o nome e a senha, e seus convidados conectam escaneando com a câmera do celular.

É grátis?

Sim. Sem cadastro, sem marca d'água e sem limite.
