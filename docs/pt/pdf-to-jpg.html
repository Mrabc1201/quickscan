Perguntas frequentes

Como converter PDF para JPG?

Escolha seu PDF, selecione a qualidade e clique em Converter. Cada página vira uma imagem para baixar.

É grátis e privado?

Sim. É grátis, sem marca d'água e roda no seu navegador, então seu PDF nunca é enviado.

Posso converter um PDF com muitas páginas?

Sim. Com mais de uma página, você também recebe um único ZIP com todas as imagens.

Qual qualidade escolher?

Alta serve para quase tudo. Escolha Muito alta só para imprimir, pois os arquivos ficam grandes.
